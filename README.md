# GRC Risk Assessment — BrightPay Financial

## Project Overview
A full enterprise cybersecurity risk assessment for BrightPay Financial,
a fictional fintech company. Conducted using the NIST Cybersecurity 
Framework (CSF) 2.0.

## What's Included
- Risk Register: 15 identified risks with likelihood/impact scoring,
  current controls, and recommended controls
- Full Risk Assessment Report: 7-page formal report including gap 
  analysis across all 6 NIST CSF functions and executive summary
  written for non-technical leadership

## Frameworks Used
- NIST CSF 2.0 (Govern, Identify, Protect, Detect, Respond, Recover)

## Skills Demonstrated
- Enterprise risk assessment and risk register development
- NIST CSF gap analysis
- Compliance documentation
- Executive-level security reporting

## Tools Used
- Google Sheets (risk register)
- Microsoft Word / PDF (formal report)
- GitHub (documentation and version control)
